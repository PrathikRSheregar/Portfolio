# Prathik Sheregar - Portfolio

Plain HTML, CSS and JavaScript. No build step.

## Run in VS Code
1. Unzip and open the folder: File > Open Folder.
2. Install the "Live Server" extension (VS Code will suggest it).
3. Right-click `index.html` > Open with Live Server.

## Or from the terminal (needs Node.js)
    npm start

## Edit
- Content: `index.html`
- Styling: `css/style.css`
- Animations and tech-stack list: `js/main.js` (arrays `row1`, `row2`)
- Photo: replace `assets/photo.jpg`

## Deploy
Push to GitHub and import the repo on Vercel or Netlify (no settings needed).

## Easy updates
- CGPA: change the number inside `<span id="cgpa">` in `index.html` (Education section).
- Project links: each project card has a commented-out `plinks` block. Paste your repo / live-demo URLs there and uncomment it.
